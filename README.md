Mekler AI provides bounded AI assistant services that enable agents to perform tasks such as file checking, research, email handling, and more. Their platform offers a free trial with limited usage and paid plans, detailed pricing, and clear service limits. The company emphasizes privacy, support via email, and integrates with remote MCP and HTTP APIs for developers. It aims to augment AI assistants without replacing them, ensuring transparent operations and compliance.

**Areas:** Company · AI · Assistant · Services · Automation

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Mekler AI: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
